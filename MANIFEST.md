# Manifest: configs, seeds and the producer of every saved result

Generated by `scripts/make_manifest.py`; `tests/test_manifest.py` checks that it is complete.

Latent extraction is not bitwise reproducible (paper Sections 3.1 and 3.2), and kernels are non-deterministic, so a seed fixes data order and initialization but not the bits of a trained checkpoint.
